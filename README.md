# Order bot — приём заказов для оптового поставщика

Telegram-бот на Python 3 / aiogram 3, который принимает заказы поваров текстом и
голосом, разбирает позиции, сопоставляет их с прайсом Excel, уточняет непонятное
кнопками и отправляет готовый заказ менеджеру.

---

## Что умеет

- **Текст и голос.** Голосовое скачивается, конвертируется через `ffmpeg` и
  распознаётся Gemini; если Gemini недоступен — офлайн-моделью Vosk (русский).
- **Разбор заказа.** DeepSeek (JSON) → Gemini (JSON) → локальный детерминированный
  парсер. Локальный парсер работает всегда и не зависит от внешних API.
- **Сопоставление с прайсом.** `rapidfuzz` + `pymorphy3` (лемматизация) +
  синонимы из Excel. Неоднозначности («масло», «сыр») выносятся на кнопки.
- **Количество.** Если повар не назвал количество — бот предлагает кнопки
  1/2/3/5/10/20 или ввод числом.
- **Единицы.** кг/г, л/мл, штуки, упаковки, коробки, вёдра, мешки; «5 бутылок
  молока» при фасовке 1 л пересчитывается в 5 л.
- **Дата и время.** «завтра», «послезавтра», «в пятницу», «4 ноября», «к 10:30»,
  «к десяти», «срочно»; часовой пояс `Asia/Tashkent`.
- **Заказ менеджеру.** После подтверждения — карточка заказа с позициями, суммами,
  комментарием и кнопками статуса («В работу», «Доставлен», «Отменить»).
- **История.** SQLite: черновики, заказы, позиции, статусы; `/last`, `/orders`,
  `/order 12`.
- **Надёжность.** Черновики хранятся в БД (переживают перезапуск), кнопки
  защищены от повторного нажатия, HTML экранируется, systemd-автозапуск.

## Настройки `.env`

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather (обязателен) |
| `MANAGER_CHAT_ID` | chat_id упаковщика (панель заказов); задаётся только здесь |
| `COURIER_CHAT_ID` | chat_id доставщика; получает собранные заказы и фиксирует оплату |
| `DEEPSEEK_API_KEY` | ключ DeepSeek (опционально) |
| `GEMINI_API_KEY` | ключ Gemini (поддерживаются форматы `AIza...` и `AQ...`) |
| `GEMINI_MODEL` | основная модель; недоступная автоматически заменяется рабочей |
| `CATALOG_PATH` | путь к прайсу |
| `DB_PATH` | путь к SQLite |
| `VOSK_MODEL_PATH` | путь к офлайн-модели |
| `TIMEZONE` | `Asia/Tashkent` |
| `FUZZY_ACCEPT` | порог автосопоставления (по умолчанию 88) |
| `FUZZY_CANDIDATE` | порог показа вариантов (55) |
| `MAX_VOICE_MB` | лимит голосового файла |

После правки: `systemctl restart order_bot`.

## Прайс

`catalog.xlsx`, лист «Прайс», колонки:

`ID | Название | Синонимы | Единица | Фасовка | Цена, $ | Категория | Остаток`

- Синонимы перечисляются через `;`.
- Бот сравнивает названия и синонимы с учётом падежей и опечаток.
- Чтобы добавить позицию — допишите строку, сохраните файл и перезапустите сервис.
- Цена указывается **за единицу** из колонки «Единица».

В комплекте 22 позиции: бекон, моцарелла, сметана 20%, курица (филе/бёдра),
сыры, сливки, молоко, масло, овощи, бакалея, соусы, шампиньоны, тесто.

## Как работает заказ

1. Клиент присылает текст или голосовое.
2. Бот распознаёт речь (Gemini/Vosk), разбирает заказ (DeepSeek/Gemini/локально).
3. Позиции сопоставляются с прайсом:
   - уверенное совпадение → в заказ;
   - несколько похожих → кнопки выбора;
   - не найдено → «Нет в прайсе» (уйдёт упаковщику как комментарий) или «Пропустить».
4. Если количество не названо → кнопки 1/2/3/5/10/20 или ввод числом.
5. Итоговая карточка: позиции, количество, цены, сумма, дата, комментарий.
6. Заказ сохраняется в БД и уходит **упаковщику**.
7. Упаковщик: «Принять» → «Собран — доставщику». Заказ уходит **доставщику**
   с адресом, телефоном и суммой к оплате.
8. Доставщик: «Выехал» → «наличные»/«Наличные получены» → «Доставлено».
   Без отметки оплаты закрыть доставку нельзя.
9. Клиент и упаковщик получают уведомления; статус, способ оплаты, сумма и
   время доставки пишутся в PostgreSQL.

### Оплата

Сейчас бот фиксирует **оплату наличными при получении**:
доставщик принимает оплату на месте и подтверждает её в карточке. Это не
онлайн-эквайринг: для автоматического списания с карты нужен мерчант-договор
и API-ключи платёжного провайдера. Без них бот не имеет права проводить
реальные онлайн-платежи.

## Роли и панель менеджера

- **Клиент/повар** — `/start` показывает приветствие и клиентское меню
  (прайс, последний заказ, помощь). Текст и голос создают заказ.
- **Упаковщик** (`MANAGER_CHAT_ID`) — `/start` показывает **панель менеджера**
  (приём и упаковка заказов) с двумя кнопками:
  - **📥 Входящие заказы** — заказы в статусах «новый» и «в работе»,
    по 10 на страницу, с переходом в детали;
  - **📜 История** — **все** заказы с момента создания бота, по 10 на страницу;
    номер заказа открывает полную карточку.
- Менеджер не оформляет заказы из своего чата — его сообщения блокируются
  подсказкой панели. Для теста заказа используйте другой аккаунт.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | клиент | приветствие и клиентское меню |
| `/start` | менеджер | панель менеджера (входящие + история) |
| `/help` | все | инструкция (для менеджера — своя) |
| `/price` | все | прайс-лист |
| `/last` | повар | последний заказ |
| `/cancel` | повар | отменить текущий черновик |
| `/id` | все | chat_id / user_id |
| `/orders` | менеджер | входящие заказы |
| `/order 12` | менеджер/автор | детали заказа |

Назначение менеджера:

- **только** через `MANAGER_CHAT_ID` в `.env` и перезапуск сервиса;
- команды смены менеджера в боте нет — из Telegram это невозможно;
- менеджер проверяется по ID на всех операциях (`/orders`, `/order`,
  панель, кнопки статусов).

## Голос

1. Файл `.ogg` скачивается в `data/voice/`.
2. Если ключ Gemini рабочий — аудио уходит в Gemini (`gemini-3.5-flash`).
3. Иначе `ffmpeg` конвертирует в WAV 16 кГц/моно → Vosk (офлайн).
4. Расшифровка показывается в карточке заказа как «🎙 Расшифровка».
5. Временные файлы удаляются.

Vosk на 1 vCPU распознаёт короткое голосовое за несколько секунд. Качество ниже
Gemini, но работает без интернета и без ключей.

### Заменить токен

```bash
cd /root/order_bot
./scripts/set_token.sh 'НОВЫЙ_ТОКЕН_ИЗ_BOTFATHER'
```

Скрипт обновит `.env`, выставит `chmod 600`, перезапустит сервис и покажет логи.

```bash
nano /root/order_bot/.env     # MANAGER_CHAT_ID=...

```

Из Telegram менеджера сменить нельзя — это сделано намеренно.

```bash
# GEMINI_API_KEY=AIza... или AQ...
systemctl restart order_bot
```

Ключ DeepSeek начинается с `sk-`. Ключ Gemini — `AIza...` или новый `AQ...`.

## Безопасность и обслуживание

- `.env` содержит секреты: права `600`, не коммитить в git.
- Проверка логов: `journalctl -u order_bot -f`.
- Бэкап: `cp /root/order_bot/data/orderbot.db` и `catalog.xlsx`.
- Обновление кода: заменить файлы, `systemctl restart order_bot`.
- Рекомендуется сменить root-пароль VPS и настроить SSH-ключи.
- Бот не ограничивает круг пользователей: любой, кто знает бота, может прислать
  заказ. При необходимости добавьте allow-list в `handlers.py`.
