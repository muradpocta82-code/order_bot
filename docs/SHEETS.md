# Выгрузка в Google Sheets (F2)

Что это: команда `/export N` отдаёт Excel-файл менеджеру в Telegram, а если подключена
таблица Google — те же строки дописываются в лист `Заказы`. Подключение необязательно:
без него бот работает как раньше, `doctor.py` просто показывает ⚠️.

## Что нужно от владельца (один раз, ~10 минут)

1. Открыть <https://console.cloud.google.com/> → создать проект (например, `order-bot`).
2. Включить API: **Google Sheets API** (Библиотека → Google Sheets API → Включить).
3. Создать **сервисный аккаунт**: IAM и администрирование → Сервисные аккаунты → Создать.
   Имя любое. Роль проекта не нужна.
4. У этого аккаунта: Ключи → Добавить ключ → JSON. Файл скачается на компьютер.
5. Создать Google-таблицу, в ней лист с именем **Заказы**.
6. Нажать в таблице «Доступ» (Поделиться) и выдать права **Редактор** адресу
   сервисного аккаунта — он вида `order-bot@order-bot-123456.iam.gserviceaccount.com`.
7. Идентификатор таблицы — часть ссылки между `/d/` и `/edit`:
   `https://docs.google.com/spreadsheets/d/`**`1AbC...xyz`**`/edit`.
8. Положить JSON на сервер и прописать в `.env` две строки:

```
GOOGLE_SA_FILE=/opt/order_bot/google-sa.json
SHEETS_ID=1AbC...xyz
```

9. `systemctl restart order_bot`, затем в боте `/sheets` — должно ответить «подключён».

Секреты: файл ключа не пересылать в чат, права `600`, владелец `orderbot`.

## Как проверить

- `/sheets` — статус: подключён / чего не хватает.
- `/export 7` — заказы за неделю: приходит Excel и строки появляются в таблице.
- `venv/bin/python scripts/doctor.py` — строка «выгрузка в Google Sheets».

## Если что-то не так

- «ключ сервисного аккаунта не найден» — проверьте путь в `GOOGLE_SA_FILE` и права на файл.
- «не задан SHEETS_ID» — в `.env` пустая или неверная строка.
- Пришёл токен, но строки не появляются — таблица не расшарена на адрес сервисного
  аккаунта (права **Редактор**, не «Просмотр»).
- Ошибка 403 `PERMISSION_DENIED` — то же самое: нет доступа к таблице.
