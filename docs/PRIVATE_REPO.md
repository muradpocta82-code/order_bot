# Приватный репозиторий (A3)

Зачем: сегодня вся история и теги живут только на сервере. Если сервер потеряется,
останется архив на ноутбуке владельца (`order_bot_backup_*.tgz`). Приватный репозиторий
даёт резервную копию истории и возможность откатиться к любому тегу.

## Что нужно от владельца (один раз, ~10 минут)

1. Завести аккаунт на GitHub (или Codeberg) — **это делает владелец**, агент не регистрирует.
2. Создать **приватный** репозиторий, например `order-bot`. Без README и без лицензии —
   пустой.
3. В репозитории: Settings → Deploy keys → Add deploy key → вставить публичный ключ
   сервера (он ниже, `order_bot.pub`), поставить галочку **Allow write access**.
4. Сказать агенту адрес репозитория — он пропишет `origin` и сделает первый `git push`.

Публичный ключ сервера лежит в `/root/.ssh/order_bot.pub` (создаётся командой
`ssh-keygen -t ed25519 -N "" -f /root/.ssh/order_bot`); в чат его выводить не нужно,
достаточно передать владельцу файлом или через `cat` на сервере.

## Что делает агент

```bash
cd /opt/order_bot
git remote add origin git@github.com:<владелец>/order-bot.git
GIT_SSH_COMMAND="ssh -i /root/.ssh/order_bot" git push -u origin main --tags
```

Проверка: `git ls-remote origin | head` показывает ветку `main` и теги `deploy-…`.

## Что нельзя класть в репозиторий

- `.env` и `.env.staging` — только `.env.example` (уже так).
- `catalog.xlsx` (прайс — коммерческие данные), `data/`, `certs/`, дампы базы.
- Ключи Google, токены ботов, пароль базы.

Проверяется перед первым пушем: `git status --short` и `.gitignore`. Если секрет всё же
попал в историю — репозиторий пересоздать, а секреты перевыпустить.

## Версии пакетов

`requirements.txt` — что нужно человеку; `requirements.lock` — точные версии, которые
реально стоят на сервере. Обновляется командой `bash scripts/make_lock.sh` (она же
сверяет `requirements.txt` с окружением). После обновления пакетов — прогнать
`bash scripts/test_all.sh`, потом коммит.

## Как часто пушить

После каждой задачи, вместе с тегом `deploy-ГГГГММДД-N`:

```bash
git add -A && git commit -m "…" && git tag deploy-20261127-1
git push --follow-tags
```
